Покупатель написал, оплатил или оставил отзыв — событие приходит в ваш бот. Оттуда можно ответить, открыть заказ, выбрать шаблон или изменить настройки магазина. Для входа достаточно `/start` или `/menu`; остальные действия находятся в меню.

**CXH FP работает на вашем компьютере или сервере.** Настройки, товары и плагины хранятся у вас. В публичной сборке нет чьих-либо аккаунтов, ключей, переписок и товарных файлов.

## 🎛 Панель без лишних команд

- **Команды:** `/start` и `/menu` открывают профиль и разделы магазина, `/restart` перезапускает бот. Команды загруженных плагинов также появляются в меню Telegram; для FazerCards — `/fzr`.
- **Одна карточка:** при переходах меню редактируется, а не засоряет чат новыми сообщениями. «Назад» возвращает к предыдущему экрану.
- **Короткие кнопки:** понятные названия, обычные эмодзи и немного цвета для основных действий.
- **Два языка:** русский и английский. Язык выбирается в установщике и меняется в панели.
- **Без предпросмотров:** ссылки в сообщениях не превращаются в большие карточки.
- **Premium-оформление:** анимированные эмодзи используются при подтверждённом Premium владельца бота; иначе остаются обычные.

В «Лоты и цены» бот получает расчёт у FunPay: показывает сумму продавца, итог покупателя по СБП и разницу. Комиссия не зашита в постоянный процент — итог зависит от условий конкретного лота.

## 🚀 Установка

Понадобятся **Python 3.11**, ваш `golden_key` FunPay и токен бота из [@BotFather](https://t.me/BotFather). Создайте бота с именем **CXH FP** и username, который начинается с `coxerhubfp` и заканчивается на `bot`, например `coxerhubfp_shop_bot`. Токен и ключ вводятся скрыто; отправлять их в чужие чаты не нужно.

Скачайте архив из [релизов](https://github.com/exfador/cxh-fp/releases/latest) и распакуйте в отдельную папку. Мастер сначала предлагает язык, готовит окружение и проверяет введённые настройки. При обычном запуске пакеты заново не устанавливаются.

### 🪟 Windows

1. Установите Python 3.11 с сайта [python.org](https://www.python.org/downloads/) и отметьте **Add Python to PATH**.
2. Запустите **Setup.bat**, выберите язык и заполните настройки.
3. Запускайте бот через **Start.bat**.

Из терминала: `py -3.11 setup.py`, затем `py -3.11 start.py`.

### 🐧 Linux

В распакованной папке:

```sh
python3.11 setup.py
python3.11 start.py
```

Для постоянной работы есть шаблон `coxerhub-bot@.service`. Настройте пути в нём под свою установку и запускайте службу от отдельного пользователя. [Подробная инструкция](docs/user-guide.md).

### ⚡ Автоустановка на Ubuntu

Для Ubuntu **20.04 / 22.04 / 24.04 LTS**, x86_64 и ARM64:

```sh
curl -fSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/exfador/install-cxh-fp/refs/heads/main/install_cxh_fp.sh -o cxh-fp.sh && sudo bash cxh-fp.sh
```

Сначала выберите язык. Установщик проверит подписанный релиз, подготовит Python 3.11 и предложит ввести настройки. Бот работает от пользователя `coxerhub`, файлы находятся в `/opt/cxh-fp`, служба — `cxh-fp`. Системный Python остаётся на месте. Если Python 3.11 ещё нет, первая сборка может занять 10–20 минут; число процессов сборки ограничено памятью сервера.

Повторный запуск сохраняет настройки и установленные плагины. Существующие установки в других папках автоматически не переносятся. Проверить план без установки: `bash cxh-fp.sh --preview --language ru`. [Установщик и подробности](https://github.com/exfador/install-cxh-fp).

### 🍎 macOS

Установите Python 3.11, откройте терминал в папке проекта:

```sh
python3.11 setup.py
python3.11 start.py
```

### 🐳 Docker

```sh
docker compose build
docker compose run --rm coxerhub-bot
docker compose up -d
```

Настройки, журналы, товары и плагины сохраняются в папках хоста. Для обновления контейнера пересоберите образ и перезапустите его; кнопка установки внутри контейнера код образа не заменяет.

## 🧩 Плагины

Откройте **Плагины → Добавить** и отправьте файл `.py` либо ZIP до 20 МБ. Внутри ZIP может лежать модуль с папками зависимостей рядом с ним, в том числе в одной общей папке. Архив проверяется до установки: запрещены выход из папки, ссылки, конфликтующие имена и чрезмерная распаковка. После установки нужен перезапуск.

Выбирайте сборку плагина под свою ОС. RAR предварительно перепакуйте в ZIP. Включённые Python-плагины работают с правами бота и имеют доступ к его данным — проверка архива не заменяет проверку исходного кода.

Новости проекта и расширений: [@funpay_coxerhub](https://t.me/funpay_coxerhub).

## 🔄 Обновления

Бот периодически проверяет релизы **этого репозитория**. Проверить вручную можно в **Инструменты → Обновления**.

1. Выходит новый релиз с цифровой подписью проекта.
2. В личный чат авторизованного оператора приходит уведомление.
3. Вы нажимаете **«Обновить и перезапустить»**.
4. Бот проверяет подпись, версию и контрольные суммы, сохраняет предыдущий код и устанавливает новый.
5. После успешного запуска приходит результат. Если новая версия не запустилась, восстанавливается предыдущая.

**Без нажатия кнопки установка не начинается.** Настройки, товары, плагины и собственное оформление бота сохраняются. Релиз без правильной подписи или архив с изменённым содержимым не устанавливается. Сбой проверки релизов не останавливает магазин.

В версии 1.1 кнопка устанавливает обновления с прежними зависимостями. Если релиз меняет пакеты, бот предложит сначала запустить `setup.py`. [Как устроена проверка](docs/update-policy.md).

## 🔐 Ваши данные и резервные копии

- Конфигурация, товарные файлы, установленные плагины и журналы исключены из публикации и релизов.
- Доступ к панели и выгрузкам ограничен авторизованными пользователями в их личных чатах.
- Текущий журнал — `logs/log.log`; старые записи лежат в `logs/archive`, новые `log.log1` не создаются.
- В терминале остаются короткие события. DEBUG и диагностика записываются в журнал с маскированием известных секретов; содержимое товара и личных сообщений не журналируется.
- Копию можно создать и восстановить в **Инструментах**. Она содержит рабочие настройки и товары: храните её приватно.

Подпись сообщений:

```text
🦊 CXH FP
```

Ссылок в подписи нет: FunPay не любит ссылки на сторонние ресурсы в чатах. Свою подпись можно задать командой `/watermark` или в «Профиль → Подпись сообщений».

Аватар и описание лежат в [`bot-profile`](bot-profile/README.md). Замените фотографию или тексты и перезапустите бот.

## 🛠 Исходники и проверки

В репозитории находятся файлы бота, установщики, инструкции и регрессионные тесты в `.github/tests`. Запуск проверок без подключения к аккаунтам: `.venv/Scripts/python.exe -B -m unittest discover -s .github/tests -v` (Linux/macOS: `.venv/bin/python`). Макеты и инструменты подготовки релизов хранятся в рабочей копии разработчика.

GitHub Actions проверяет исходники, зависимости и запуск установщика на Windows, Linux и macOS. Подписи релизов и контрольные суммы проверяются самим ботом перед обновлением. Источники базовых компонентов указаны в [NOTICE](NOTICE).
